# Historical changelog

Detailed pre-2.0 release notes described intermediate model 1.x formulas,
parameters and publication files. They were removed from the active changelog
because those statements are not valid documentation for ProcuraCost 2.0.

The complete historical record remains available in Git history. Supporting
audits and verification runs are preserved in [`audits/`](audits/), while the
corresponding articles, research protocols and plans are stored in the adjacent
archive directories.

Do not copy claims or values from the historical record into current materials
without re-verifying them against model 2.0 and the primary source.
