# ProcuraCost 1.x Archive

This directory contains superseded model 1.0–1.2 research materials, article
drafts, audits, project plans, replication examples and retired site content.
They are retained only for provenance.

Do not use these files as current sources of:

- equations or parameter values;
- legal thresholds;
- empirical claims or bibliography;
- publication-ready article text;
- survey, preregistration or validation design.

The archive is internally inconsistent by design because it preserves the state
of successive historical drafts. Current sources of truth are:

- [`RESEARCH.md`](../../../RESEARCH.md) — working paper and evidence audit;
- [`docs/MODEL_PARAMETERS.md`](../../MODEL_PARAMETERS.md) — model contract;
- [`docs/articles/doktorat/00-shared-foundation.md`](../../articles/doktorat/00-shared-foundation.md) — doctoral-cycle foundation;
- [`docs/research/model_specification_draft.md`](../../research/model_specification_draft.md) — compact specification;
- [`replication/outputs/`](../../../replication/outputs/) — generated model 2.0 outputs.

Nothing under this archive should be linked from the public application.
