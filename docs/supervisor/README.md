# Pakiet dla promotora — ProcuraCost 2.2

**Stan na:** 26 lipca 2026

**Wersja modelu:** 2.2.1

**Adresat:** prof. Krzysztof Piech (powtórna recenzja po modelu 1.x)

## Cel spotkania

Uzyskać ocenę, czy warunkowa teza Tunnel–Field, siedmiowymiarowy model
decyzyjny i proponowany projekt empiryczny tworzą spójny rdzeń cyklu
doktorskiego. Spotkanie nie ma zatwierdzać gotowych wyników empirycznych:
ProcuraCost 2.2 jest modelem transparentnych scenariuszy i żadne dane nie
zostały zebrane.

> **Jeżeli ma Pan czas na jeden dokument**, proszę o
> [`05-co-zmienilo-sie-po-recenzji.md`](05-co-zmienilo-sie-po-recenzji.md). Opisuje, co
> wynikło z Pana poprzednich uwag, co się z tym stało, oraz jakie błędy — w tym
> wprowadzone przez sam projekt przy okazji poprzedniej korekty — wykrył audyt
> przeprowadzony przed tym spotkaniem.
